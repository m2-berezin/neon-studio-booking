# neon-studio-booking

“Create a mobile-first web app called ‘7T7Studios’.
Design: pure black background (#000), text in off-white (#EDEDED). Top-center logo placeholder, Times New Roman, subtle neon glow/shadow. Rounded cards, large tap targets.
Tabs (bottom nav): Home, Book, Rewards, Messages, Profile.
Home shows 6 cards: Book a Session, Exclusive Beats, My Projects, Rewards, Subscriptions, Studio Info.
Use Supabase for auth + data. Enable email/password + magic link. After login, land on Home.”
